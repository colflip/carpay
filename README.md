# CarPay · 车辆全周期成本计算器

纯前端离线计算的购车成本测算工具，数据仅保存在浏览器本地（localStorage），不上传任何服务器。

## 功能

- **购车测算**（可用）：车价构成、补贴、购置税（自动/手动）、保险、杂费、全款/分期（等额本息），右侧汇总卡片分层展示明细并高亮落地总价
- **用车成本 / 卖车损益**：开发占位，架构已预留扩展
- 明暗主题切换、GitHub 入口、表单本地持久化
- 复制明细文本、导出 txt / 图片（汇总卡片 PNG）、每一项均带 tooltip 说明

## 计算口径

- 计税基数 = 裸车原价 + 选装包 - 官方优惠 - 门店优惠 - 金融返点（贷款购车时返点冲减开票价与计税基数，并同额降低首付与月供基数）；开票价低于最低计税价时按最低计税价核定
- 购置税 = 计税基数 ÷ 1.13 × 档位税率（全额 10% / 减半 5% / 免征 0），减半档自动套用每辆 1.5 万减税上限（新能源 2026-2027 政策）；燃油车默认全额、新能源默认免征，均可手动修改；换电车型按不含电池价格计税
- 车船税随交强险代收，按排量分档、各省标准不同（燃油默认 420 元/年，纯电动乘用车不征收，默认 0），可修改
- 上牌费默认 125 元（车管所工本费：号牌 100 + 行驶证 10 + 登记证书 10 + 临牌 5），4S 代办一般 500-2000 元
- 置换、报废、首购补贴直接抵扣总价，不参与计税
- 付款方式：全款 / 首付比例分期（按首付比例确定贷款）/ 固定额度贷款（直接输入固定贷款额度）；支持前 N 期免息贴息方案（如「5年2年免息」= 期数 60 + 免息 24），免息期不计息、剩余期数按年利率计息，月供全程等额：本金 × k ÷ (1 + N × k)，k 为剩余期数的等额本息期供率（无免息时即标准等额本息公式）
- 提前还款：以时点芯片选择（不提前 / 12 / 24 / 36 期，须小于总期数），到第 N 期一次性结清剩余本金并支付提前还款手续费；结清前利息按免息期数口径计算（免息期内不计息，之后按年利率计息），如选 24 期即 2 年到期后结清
- 导出图片为汇总卡片快照（含免责声明、不含操作按钮），基于 html-to-image 按需加载
- 所有金额输入框下方实时显示中文大写金额（如 150000 → 壹拾伍万元整），避免量级输错
- 贷款落地总价 = 首付 + 月供 × 期数 + 购置税 + 保险 + 杂费 - 补贴与返点

## 开发

```bash
npm install
npm run dev
```

## 部署到 GitHub Pages

1. 修改 `src/components/CarPayCalculator.tsx` 顶部的 `GITHUB_URL` 为实际仓库地址
2. 推送到 `main` 分支，`.github/workflows/deploy.yml` 会自动构建并发布
3. 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**

Vite 已配置 `base: './'`（相对路径），无需修改即可部署到 `用户名.github.io/仓库名/` 子路径。

## 技术栈

React 18 + TypeScript + Vite + Tailwind CSS + Framer Motion + lucide-react
