# 赠送权益模块 · 全网调研与落地方案

> 调研时间：2026-10-29 · 范围：4S 店常见购车赠品、厂商首任车主权益、新能源充换电与家充桩、免费保养/延保、车机流量、权益兑现风险，以及与 CarPay 购车/用车/卖车三段口径的衔接。

---

## 一、调研结论

### 1.1 市面权益可分四类，不能统一按标价相加

| 类型 | 常见项目 | 合理估值依据 | 进入哪段计算 |
| --- | --- | --- | --- |
| 现金等价类 | 油卡、充电卡、维修基金、工时券 | 可抵扣面额；有限制时按预计使用额封顶 | 用车成本对应年度 |
| 次数/额度类 | 免费小保养、洗车、充电/换电、车机流量 | `可用次数 × 单次实际替代价`，再受持有期和有效期限制 | 用车成本逐年抵扣 |
| 实物/一次性服务 | 车膜、脚垫、记录仪、充电桩、上牌、精品 | 自购替代价，不采信销售“礼包价”；用户确有需求才计价值 | 独立展示，不直接减落地价 |
| 风险保障类 | 原厂延保、三电终身质保、道路救援、取送车 | 无事故/故障时不会产生现金回收，属于或有价值 | 独立展示，不计确定性节省 |

**核心结论**：赠送权益不是补贴。补贴是确定减少购车付款；权益往往附带期限、次数、门店、首任车主、保养合规或不可转让条件。若将权益估值直接从落地价中再减，会虚低现金支出，并在用车成本中产生重复抵扣。

### 1.2 “硬通货”与虚高项目

- 搜索结果与购车经验文章的共同结论是：**油卡/充电卡、免费保养、工时券**价值最容易核验，优先级高；加油卡面额 1,000 元通常可视作接近 1,000 元，保养/工时券仍要看限店、限项目及定价。
- 太平洋汽车整理的常见礼包包含：1–3 次基础保养、500–2,000 元油卡/充电卡、行车记录仪、品牌车膜、脚垫等；同时建议能折现金时优先折现金，并把品牌、型号、有效期写入合同。
- 知乎文章给出典型“虚标”案例：销售口中的 2,000 元车膜、1,000 元脚垫水分较大；脚垫销售声称 400–500 元，实际进货可能不足 100 元；此类项目按销售报价的 3–4 折仍可能偏高。原厂记录仪示例官方价约 458 元，而非原厂专供品进价可能仅 200–300 元。
- 因此模块必须同时展示 **宣传标价** 与 **可兑现价值**，主数字只使用后者，默认不采信宣传价。

### 1.3 新能源权益更复杂

- 家用 7 kW 充电桩是常见购车权益。2026 年搜索结果中，第三方全套 30 米内安装约 4,600 元；厂商服务包示例约 4,599 元，裸桩约 2,799 元。估值需拆分“设备 + 基础安装米数”，车位、电表、超长线缆等自费部分不能计入赠送价值。
- 免费充/换电通常按月次数或度数发放。搜索结果可见典型政策为每月 4 次免费换电；价值必须按实际里程需求封顶，不能用理论最大次数乘满持有期。
- 车机流量政策差异大。上海市消保委对 41 个汽车品牌进行过调查，公开搜索摘要指出消费者很难查清续费标准和基础/娱乐流量边界；典型方案包括 20 GB/月持续 3 年、基础流量终身免费等。不能用手机流量价格简单估值，应以车企续费套餐或用户愿付价格填写。
- “三电终身质保”通常附带首任非营运车主、按期在授权店保养、事故/改装限制、车辆过户失效等条件。它不是确定性现金节省，不应按电池更换价全额计入。

### 1.4 权益必须有兑现状态与合同证据

- 购车赠品不兑现、口头承诺难举证是高频投诉；搜索到的司法案例明确赠品可以构成购车合同的一部分，未兑现可构成违约。
- 高价值项目必须记录：**名称、品牌/型号、数量/次数、有效期、使用门店、转让限制、交付时间、合同是否写明**。
- 模块不只是计算器，还应是交付清单：`待写入合同 → 已写入合同 → 已领取 → 已使用 → 已过期/放弃`。

## 二、产品定位

### 2.1 推荐位置

在购车测算页新增独立的 **「赠送权益」** 模块，放在「补贴」之后、「购置税与保险」之前。

原因：权益在成交谈判阶段确认，属于购车信息；但其经济价值主要发生在后续用车阶段，因此数据由购车页录入，计算结果同时联动用车成本与卖车损益。

### 2.2 模块要回答的四个问题

1. 销售承诺了什么，是否写入合同？
2. 这些权益真实能值多少，而不是宣传价值多少？
3. 在计划持有期内能实际用掉多少？
4. 用掉后能少花多少用车成本，哪些权益不能当现金算？

### 2.3 主数字

展示三个数字，避免把不同性质混成一个总额：

- **可兑现价值**：按规则和持有期预计能使用的权益价值。
- **确定性节省**：会实际抵扣能源、保养、保险、洗车等现金支出的金额。
- **保障参考价值**：延保、终身质保、道路救援等或有权益，仅展示，不进入总成本。

同时展示：`宣传总价值 ¥X → 可兑现 ¥Y（兑现率 Z%）`。

## 三、权益分类与字段设计

### 3.1 快速新增模板

首屏提供 8 个高频模板，点击后生成可编辑权益卡片：

1. 免费基础保养
2. 油卡 / 充电卡
3. 家用充电桩
4. 免费充电 / 换电
5. 车膜 / 记录仪 / 脚垫
6. 延保 / 三电质保
7. 车机流量 / 会员
8. 其他权益

不使用固定的大表单；默认只展示已添加项，避免低频用户面对几十个输入框。

### 3.2 通用数据模型

建议建立独立存储 `carpay:benefits-form:v1`，避免继续膨胀 `BuyForm`：

```ts
export type BenefitCategory =
  | 'maintenance'
  | 'energy'
  | 'charging'
  | 'accessory'
  | 'warranty'
  | 'digital'
  | 'service'
  | 'other';

export type BenefitValuation = 'cash' | 'count' | 'annual' | 'reference';
export type BenefitStatus = 'promised' | 'contracted' | 'received' | 'used' | 'expired' | 'waived';
export type BenefitCostBucket = 'none' | 'energy' | 'maintenance' | 'insurance' | 'misc';

export interface BenefitItem {
  id: string;
  category: BenefitCategory;
  name: string;
  valuation: BenefitValuation;
  advertisedValue: string;
  unitValue: string;
  quantity: string;
  perYearQuantity: string;
  validYears: string;
  validUntil: string;
  realizationPct: string;
  costBucket: BenefitCostBucket;
  status: BenefitStatus;
  transferable: boolean;
  firstOwnerOnly: boolean;
  contractIncluded: boolean;
  provider: string;
  brandModel: string;
  restrictions: string;
}
```

`realizationPct` 是用户主观可兑现率，系统给保守默认值但允许修改：

| 模板 | 默认兑现率 | 理由 |
| --- | ---: | --- |
| 油卡/充电卡 | 100% | 面额透明，过期或限站时用户下调 |
| 免费保养 | 90% | 与常规保养高度重合，但受限店/期限影响 |
| 家充桩 | 100% 或 0% | 有固定车位并能安装取 100%，不能安装取 0% |
| 免费充/换电 | 80% | 受站点、次数和实际里程限制 |
| 原厂实物 | 70% | 按替代采购价，需确有需求 |
| 非原厂礼包 | 30% | 销售报价通常虚高，默认保守 |
| 车机流量/会员 | 50% | 使用需求差异大、续费价不透明 |
| 延保/终身质保 | 0% 确定性节省 | 放入保障参考价值，不进入现金节省 |

> 兑现率不是行业事实，而是防止按宣传价全额计算的产品假设；界面需明确“按你实际会使用的比例估算”。

## 四、计算口径

### 4.1 单项权益价值

```text
名义价值 =
  cash:     面额
  count:    单次替代价 × 总次数
  annual:   单次替代价 × 每年次数 × min(有效年限, 持有年限)
  reference: 用户填写的保障参考价值

可兑现价值 = min(名义价值, 持有期内实际需求上限) × 兑现率
```

状态修正：

- `expired / waived`：可兑现价值为 0。
- `used`：计入已兑现，不再出现在待使用额度。
- `promised` 且未写入合同：保留估值，但标记“高风险”，默认兑现率额外乘 70%。
- `contracted / received`：不加风险折扣。

为避免规则黑箱，界面逐项显示公式，如：`3 次 × ¥500 × 90% = ¥1,350`。

### 4.2 与用车成本联动

权益只抵扣对应成本桶，且不允许抵成负数：

```text
净能源费 = max(0, 毛能源费 − 能源权益已兑现价值)
净保养费 = max(0, 毛保养费 − 保养权益已兑现价值)
净保险费 = max(0, 毛保险费 − 保险权益已兑现价值)
净杂项费 = max(0, 毛杂项费 − 杂项权益已兑现价值)
净用车成本 = 各净成本桶之和
```

次数型权益需要按时间顺序消耗，避免“一次免费保养”被每年重复抵扣：

```text
第 y 年可用次数 =
  min(当年发生次数, 截至该年剩余赠送次数, 是否仍在有效期)

当年抵扣 = 可用次数 × min(赠送单次价值, 当年同类单次成本)
```

**重要口径**：

- 免费保养抵扣 `maintenanceTotal`，不是把宣传面额从购车落地价中减掉。
- 油卡/充电卡抵扣能源费；不超过持有期实际能源费。
- 家充桩是替代采购资产，不抵扣电费；独立展示为一次性实物价值。
- 保险补贴仍留在补贴模块，直接抵扣落地总价；“赠送首年保险”如果已折为保险补贴，不得再次添加权益。
- 上牌费若购车页已经填 0，不能再把“免费上牌”算作权益节省；可通过重复计算警告提醒。
- 延保/三电质保、道路救援不进入确定性用车成本，只进入保障参考。

### 4.3 与卖车损益联动

卖车时点只累计此前已可使用的确定性权益：

```text
全周期净支出 = 落地总价 + 毛用车成本 − 截至卖出时点权益节省 − 卖车到手价 − 退保回收
```

- 卖出后才到期/可领取的权益不计入。
- 首任车主权益默认在过户时终止，对卖车残值不加价。
- 明确“权益随车可转让”时，可作为卖车说明标签，但 P1 不自动提高残值，避免主观双算。
- 逐年最优卖出年必须按每年累计权益重新计算，不能把总权益一次性套到所有年份。

## 五、界面方案

### 5.1 购车页录入区

```text
赠送权益                                      + 添加权益
[免费保养 3 次] [油/充电卡] [家充桩] [更多]

┌ 免费基础保养                         已写合同 ┐
│ 3 次 × ¥500 / 次     有效期 2 年              │
│ 可兑现 ¥1,350   宣传 ¥2,000   兑现率 90%      │
│ 限本店；含机油机滤工时                         │
└───────────────────────────── 编辑 ┘

可兑现价值 ¥5,949  ·  确定性节省 ¥1,350
保障参考 ¥2,000    ·  2 项待写入合同
```

交互：

- 模板点击后用紧凑抽屉/展开卡编辑，不新开页面。
- 项目标题行可折叠；默认展开刚添加项。
- 高风险条件以黄点提示，不使用满屏红色警告。
- 支持拖动排序不是刚需，按类别固定排序即可。

### 5.2 用车成本结果区

在构成条下增加一行：

```text
赠送权益节省  -¥1,350
毛用车成本 ¥42,800 → 权益后 ¥41,450
```

明细组展示实际抵扣：

- 能源权益抵扣
- 免费保养抵扣
- 保险/服务权益抵扣

逐年表增加窄列「权益 −」，显示当年实际节省；总成本仍为净额。表头 Tip 解释毛额与净额。

### 5.3 权益价值卡与交付清单

购车汇总卡新增 `赠送权益` 组，但与补贴区视觉区分：

- 补贴使用绿色负数，参与落地总价。
- 权益用蓝紫色标签，显示“另含权益估值”，不参与落地总价。
- 导出明细和品牌海报应同时展示“落地价”和“另含权益”，不能写成“权益后落地价”。

新增合同清单入口：

```text
待确认 2
□ 品牌/型号已写明
□ 数量、次数与有效期已写明
□ 使用门店与限制已写明
□ 交付时间及未兑现处理已写明
```

## 七、分期落地建议

### P0：可用闭环

- 独立权益存储与 8 类模板。
- 新增/编辑/删除权益。
- 宣传价值、可兑现价值、确定性节省、保障参考四个口径。
- 合同状态与限制备注。
- 购车汇总、复制明细、TXT/图片导出。
- 不影响现有落地总价，彻底避免“权益当现金优惠”。

### P1：三段联动（推荐同一版本完成）

- 免费保养、油卡/充电卡、免费充换电按年抵扣用车成本。
- 用车逐年表显示权益节省。
- 卖车按卖出月份截断权益，最优卖出年同步重算。
- 重复计算警告：保险补贴、免费上牌、购车页已减为 0 的费用。

### P2：增强能力

- 到期提醒与“本年待用权益”。
- 权益方案对比：现金优惠 vs 赠品礼包。
- 可导入/导出权益 JSON。
- 随车转让权益只做残值标签，不自动估价。

不建议首版做：品牌车型权益数据库。政策变化频繁、地区和订单日期差异大，静态库很快过期；先让用户依据订单权益手动录入，保留来源链接和订单日期更可靠。

## 八、验收标准

1. 未添加权益时，三个现有模块结果与当前版本逐分一致。
2. 赠送 3 次保养只能抵扣实际发生的前三次保养，不能使保养成本为负。
3. 2 年有效权益在第 3 年及以后不再抵扣。
4. 3 年后卖车时，只计算前三年已可用权益；5 年权益不能提前全额计入。
5. 保险补贴与赠送保险同时录入时出现重复计算警告。
6. 延保/三电质保只进入保障参考，不降低现金总成本。
7. 口头承诺项目显示高风险；写入合同后风险折扣取消。
8. 旧版 localStorage 无权益数据时正常迁移，默认空列表。
9. 复制明细、TXT、海报中的权益数字与页面一致。
10. 手机端添加/编辑项不横向溢出，按钮触控区不小于 44 px。
