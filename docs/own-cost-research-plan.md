# 用车成本模块 · 全网调研与落地计划

> 调研时间：2026-10-25 · 范围：国外三大权威口径（Edmunds / AAA / KBB）、国内平台工具（汽车之家 / 懂车帝 / 爱卡 / 小熊油耗）、开源项目（autocosts）、成本口径细项（保险 NCD / 保养周期 / 易损件 / 电价 / 折旧 / 杂项）

## 一、同类项目调研

### 1.1 国外权威口径

| 项目 | 周期假设 | 成本分类 | 特色输出 |
| --- | --- | --- | --- |
| [Edmunds True Cost to Own](https://www.edmunds.com/tco.html) | 5 年 / 15,000 英里/年 | 折旧、税费、金融利息、保险、燃油、保养、维修 | 分车型逐年费用曲线 |
| [AAA Your Driving Costs](https://exchange.aaa.com/automotive/aaas-your-driving-costs)（[2026 报告](https://newsroom.aaa.com/2026/09/aaa-new-vehicle-ownership-costs-hit-12863-annually)：年均 $12,863） | 年度 | 燃料、保养/维修/轮胎、保险、牌证税费、折旧、金融费用 | **每英里成本**（燃料 13¢/mi、保养轮胎 11¢/mi） |

| [美国能源部 AFDC 计算器](https://afdc.energy.gov/calc) | 自定义 | TCO + 排放 | 能源车型对比 |
| [autocosts（开源）](https://github.com/jfoclpf/autocosts) | 自定义 | 燃料、保养、保险、折旧等 | 多语言/多国数据 |

**共性**：① 固定测算窗口（多为 5 年）；② **含折旧**（视为最大持有成本）；③ 提供单位里程成本；④ 有逐年明细。

### 1.2 国内工具现状

- [爱卡汽车 · 养车费用计算器](https://yp.xcar.com.cn/tools/fy)：简单表单（油费/保养/保险/停车等），无逐年、无口径说明。
- 汽车之家养车成本调查口径：**7 大项 = 燃油、保险、保养、停车、车船税、洗车、杂费**，样本月均约 1,568 元（[百科口径](https://car.autohome.com.cn/baike/detail_6_42_2311.html)）。
- 懂车帝：车型页附油费/保养估算，绑车型库，不可自定义参数。
- [小熊油耗](https://www.xiaoxiongyouhao.com/fprice)：众包油耗 + 每日油价（2026-10-24：92# 8.61 元/L、95# 9.17 元/L），是能源默认值的可靠数据源。
- 各媒体测算惯例：[8 年/年 2 万公里对比](https://zhuanlan.zhihu.com/p/1948719685982991299)（油车油费 5.6 万 + 保养 0.88 万 + 保险 6.8 万 + 折旧 19 万 ≈ 32.28 万）。

**国内特点**：① **普遍不含折旧**（残值放到卖车环节感知）；② 杂项颗粒细（停车/洗车/路桥单列）；③ 几乎没有逐年视角和口径披露。

### 1.3 机会点（CarPay 的差异化）

1. **全周期贯通**：购车（落地价）→ 用车（持有支出）→ 卖车（残值损益）三段衔接，国内外均无此类轻量工具。
2. **口径透明**：每个默认值给 Tip + 计算依据外链，是本项目既有风格。
3. **折旧归属卖车损益**，用车成本只算现金支出，避免与 Edmunds 式 TCO 混淆——在计算依据中明确披露。
4. 输出**月均 + 每公里 + 持有期合计**三口径，覆盖「月度现金流」与「单位里程」两种心智。

## 二、成本口径设计（算什么、不算什么）

**核心规则（防双算）**：购车落地总价已含**首年**交强险 + 商业险 + 首年车船税（`CarPayCalculator.tsx` 现行逻辑）。用车成本模块持有 N 年时，保险与车船税只计**第 2 ~ N 年**（N−1 次）。模块内明示这一行口径。

| 成本项 | 是否计入 | 计算方式 | 默认值（油/电） | 主要依据 |
| --- | --- | --- | --- | --- |
| 能源 | ✅ 核心 | 油：油耗×油价×年里程；电：电耗×综合电价×年里程；插混：馈电油耗与电耗按纯电里程占比加权 | 8L/100km × 8.6 元/L；15kWh/100km × 0.6 元/度（家充谷电 0.3–0.5，公共综合 1.0+） | [小熊油耗](https://www.xiaoxiongyouhao.com/fprice)、[2026 充电成本](https://auto.sina.cn/2026-09-28/detail-initkpex8528436.d.html) |
| 保险续保 | ✅ | 首年保费基数 × NCD 系数逐年：1.0（首年，已入落地价）/ 0.85 / 0.70 / 0.50（连续 3 年无出险） | 基数默认从购车 tab 带入（950+3500） | [平安 NCD 说明](https://www.pingan.com/official/strategyDetail/27985424)、[太平洋车险](https://www.cpic.com.cn/c/2025-12-29/1879464.shtml) |
| 车船税 | ✅ | 第 2~N 年，每年同额（纯电为 0） | 沿用购车 tab 默认（420 元/年） | 购车模块既有 Tip（分档标准） |
| 常规保养 | ✅ | 次数 = 持有里程 ÷ 保养间隔（向上取整）；小保养单价×次数 + 大保养加价×(持有里程 ÷ 大保养间隔) | 油：1 万 km/次 × 500 元 + 3 万 km 大保养 +1,000；电：1.5 万 km/次 × 300 元（检测+空调滤为主） | [保养周期攻略](https://kuku.baidu.com/landing/tscp_doc/71318f30b98224d03ec13f7c60a9148a)、[周期表](https://zhuanlan.zhihu.com/p/502488045) |
| 易损件/维修预留 | ✅（P0 合并，P1 拆细） | P0：年均预留一栏；P1：轮胎（5–8 万 km ×4 条）、刹车片（3–6 万 km）、电瓶（2 年/6 万 km）、雨刮（6–12 月）逐项按里程折算 | 预留 油 1,500/年、电 800/年 | [易损件周期表](https://zhuanlan.zhihu.com/p/2072638026329674676)、[新浪保养清单](https://auto.sina.cn/2026-07-09/detail-inihczph8231232.d.html) |
| 停车 | ✅ | 月费 × 12 | 300 元/月（Tip：一线 500+，小城 <150，[调查区间 1,200–5,000/年](https://www.163.com/dy/article/I1LCM4HH052787PQ.html)） | 新浪/网易养车调查 |
| 洗车 | ✅ | 单价 × 频次/月 | 30 元 × 2 次/月 ≈ 600–720/年 | 同上（约 600/年） |
| 高速/路桥 | ✅ | 月均 | 200 元/月 | 调查区间 300–2,000/年 |
| 其他月均 | ✅（自由栏） | 月均（年检、违章预留等） | 0 | 年检 6 年内免上线，P2 再单列 |
| **折旧** | ❌ 不计现金支出 | 归属「卖车损益」模块；本模块提供**可开关的“折旧摊销参考行”**（默认关） | 参考曲线：首年油 15–20%/电 20–30%，其后约 10%/年；3 年保值率油 46–60%/电 43–48% | [流通协会保值率报告](https://www.cadcc.com.cn/article/3591.html)、[折旧规律](https://www.sina.cn/news/article/nihfayz8619409.html) |
| 购置税/金融利息/上牌 | ❌ | 已在购车 tab | — | 模块边界 |

## 三、计算模型

### 3.1 输入（四组，复用 LabelInput/Tip/ToggleGroup）

1. **基础**：持有年限 N（默认 3）、年行驶里程（默认 15,000 km，Tip：通勤 1–2 万属主流）、能源类型（汽油/纯电/插混，默认跟随购车 tab `vehicleType` 映射，可改）。
2. **能源**：
   - 汽油：油耗 L/100km（8）、油价元/L（8.6，Tip 注明 92# 全国均价与 95# 9.17）；
   - 纯电：电耗 kWh/100km（15）、综合电价元/度（0.6，Tip：家充谷电 0.3–0.5、公共快充综合 1.0–1.5，2026-03 起公共桩市场化浮动定价）；
   - 插混：馈电油耗（5L）+ 纯电里程占比（60%）+ 电耗（18kWh）+ 电价（0.6）。
3. **保险与税费**：首年保费基数（默认带入 950+3500）、无出险递减 ToggleGroup（逐年递减 0.85/0.70/0.50 与「固定不降」两模式）、车船税（沿用购车 tab 值，纯电 0）。
4. **保养与杂项**：保养间隔/单价、大保养间隔/加价、易损与维修预留（年）、停车月费、洗车单价×频次、高速月均、其他月均。

### 3.2 输出（结果卡 + 明细）

- **主数字：月均成本**（对齐车主「月供+月养车」心智，20px 总价样式）；副指标：年均、每公里全口径成本、持有期总成本。
- 构成占比：纯 CSS 横向条形（能源/保险/车船税/保养/易损维修/停车路桥洗车）——不引图表库，保住 html-to-image 导出图片的稳定性。
- 逐年表（P1）：第 1~N 年保险按 NCD 递减、保养次数按里程取整产生的年度波动。
- 与购车联动展示：落地总价 + 持有期用车成本 = 持有期总支出（为卖车损益模块铺垫）。

### 3.3 关键公式

```
持有里程 = 年里程 × N
能源费 = 年里程 × (油耗/100 × 油价)         // 油
      或 年里程 × (电耗/100 × 电价)         // 电
      或 加权（插混按纯电占比拆分油/电两段）
保险 = Σ(第 y 年保费)，y=2..N：基数 × NCD(y)，NCD = 0.85, 0.70, 0.5(≥4th yr)
保养 = ceil(持有里程/间隔) × 单价 + floor(持有里程/大保间隔) × 加价
杂项 = (停车 + 洗车单价×频次 + 高速 + 其他) × 12 × N
每公里 = 总成本 / 持有里程；月均 = 总成本 / (12N)
```

## 四、UI 方案（遵循现有设计系统）

- 布局沿用 buy tab：左侧表单分组卡片 + 右侧 sticky 结果卡（重置/复制明细/导出 txt/导出图片，同款水印）；移动端底部悬浮条显示**月均成本**。
- 字号纪律：正文 13–16px、主数字 20px、计算依据 15px；LabelInput 聚拢 + aria-label；Tip 智能定位。
- localStorage：独立 `OWN_FORM_KEY`，与 `BuyForm` 分开持久化；能源类型/首年保费/车船税提供「从购车测算带入」按钮（跨 tab 同步，用户可覆盖）。
- own tab 底部独立「计算依据」区块：NCD 车险规则、2026 新能源车险自主定价系数下限 0.55、保养周期表、小熊油耗油价、2026 公共充电定价机制、流通协会保值率（折旧参考行用）。
- 复制明细文本格式对齐 buy tab（含口径声明一行：首年保险/车船税已计入购车落地总价，不重复计）。

## 五、分期落地计划

### P0 · 核心可用（1 个迭代，预计 ~800 行增量）
1. `OwnForm` 状态 + `computeOwn()` 纯函数 + 单测口径（防双算规则）。
2. 能源三态（油/电/插混）、保险 NCD 递减、车船税、保养周期换算、易损预留年、停车/洗车/高速/其他。
3. 结果卡：月均主数字 + 年均/每公里/持有期合计 + CSS 占比条形。
4. 计算依据区块、复制明细、导出 txt/图片、移动端底部条。
5. 验收：油/电默认值下月均成本落在 1,200–2,200 元调查区间；插混结果介于两者之间。

### P1 · 精度与表达（第 2 迭代）
1. 易损件拆细（轮胎/刹车片/电瓶/雨刮按里程折算，替换“预留”栏，保留兜底“其他维修”栏）。
2. 逐年明细表（NCD 与保养取整波动可见）。
3. 油电对比视图：同参数双列对比（CarPay 差异化卖点）。
4. 保险「出险一次回到 1.0」情景开关。

### P2 · 生态联动（第 3 迭代，与卖车损益同步设计）
1. 折旧摊销参考行（默认关，数据来自流通协会曲线）→ 无缝衔接卖车损益模块。
2. 全周期损益汇总：落地价 + 用车成本 − 卖车所得。
3. 城市化默认值（停车/洗车按城市档位）、年检费（6 年免检后上线）、油耗电耗预设库（按车型级别）。

### 风险与对策
- **默认值争议**：所有默认值配 Tip + 依据链接，明确“调查均值，按实际修改”。
- **口径混淆**（折旧归属）：模块顶部一句话声明 + 计算依据披露，参考行默认关闭。
- **插混模型简化**：P0 用纯电里程占比加权，Tip 注明简化假设，P1 可改精确两段式。
- **单文件膨胀**（已 1919 行）：P0 起将 own 模块拆为 `ownForm.ts`（类型+默认值+computeOwn）与组件内分区，避免主文件失控。
