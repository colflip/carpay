# 卖车损益模块 · 全网调研与落地计划

> 调研时间：2026-10-25 · 范围：保值率数据（流通协会 / 精真估 / 查博士 / 瓜子）、估值方法（车300 / 重置成本法 / 54321 里程法）、卖车渠道价差（国内瓜子口径 / 海外 KBB）、费用与流程（过户 / 退保 / 解押）、政策联动（2026 以旧换新）、卖出时点共识（知乎 / 央广网 / 汽车之家）

## 一、调研发现

### 1.1 同类项目现状

| 项目 | 残值能力 | 与 CarPay 的差异 |
| --- | --- | --- |
| [车300](https://m.che300.com)（第三方估值，为全网约 95% 二手车交易提供数据） | 输入车型/上牌时间/里程 → 估值区间 + 车况记录查询 | 黑盒绑车型库，不可自定义参数，无全周期损益 |
| 精真估 / 懂车帝 / 瓜子在线估价 | 同上，瓜子按「个人直卖价 / 卖商家价」双口径出价 | 只给卖价，不回答「这台车总共亏了多少」 |
| [KBB（美国）](https://www.kbb.com/new-cars/total-cost-of-ownership) | Trade-In（车商收车）/ Private Party（个人交易）/ Retail 三档价 | 仅给三档参考价，不与购车、用车成本贯通 |
| Edmunds True Cost to Own | 折旧按 5 年逐年曲线计入 TCO，是最大成本项 | 折旧为估算值，不含贷款结清、退保、置换补贴等中国特有环节 |
| [autocosts（开源）](https://github.com/jfoclpf/autocosts) | 折旧/残值为核心成本项 | 多国均值数据，无渠道与政策维度 |

**机会点**：国内外工具要么「只估值」、要么「只算 TCO」，均不回答 **「落地价 + 用车支出 − 卖车到手 = 净亏多少，哪年卖最划算」** 这一全周期问题；贷款结清、保险退保、置换补贴联动更是空白。CarPay 三段贯通 + 口径透明是差异化核心。

### 1.2 保值率数据与估值方法

- **2026 年保值率水位**（3 年车龄）：流通协会月报口径燃油车约 **46%–51%**、新能源 **44.8%–48%**，[插混 46.8% 于 2026-04 首次超过纯电](https://zhuanlan.zhihu.com/p/2048447542606745965)；[查博士 Q3 口径](https://news.sina.com.cn/sx/2026-10-21/detail-inivyhku4823564.shtml)：增程 56.94% / 插混 56.30% / 纯电 53.84%；[瓜子 9 月](https://news.qq.com/rain/a/20260202A04SAL00)：燃油 51.1%、新能源 48%，两者差距持续缩小。
- 现有 `RESIDUAL_CURVES`（ownCostModel，油 58% / 插混 52% / 电 47%@3 年）略高于协会「指导价」口径，但曲线基数用的是**成交价（计税基数）**，整体偏保守，**沿用即可保持与用车面板折旧参考一致**。
- **业内估值方法**（[流通协会估价方法](http://www.cada.cn)、[知乎汇总](https://www.zhihu.com/question/599932029)）：重置成本法（重置成本 × 成新率）、分段折旧法（15% 固定残值 + 3/4/3 年 11%/10%/9%）、54321 里程法（30 万 km 分 5 段按 5/15~1/15 折旧）；在线工具本质 = 曲线 + 里程/车况修正。CarPay 取「曲线 × 成交价」，里程与车况修正放 Tip 与 P2。

### 1.3 卖车渠道与价差

- 国内：瓜子官方口径 **个人直卖比车商收车高约 10%**（[官方说明](https://www.guazi.com/article/rmwz/6a8d39e7c5f05a002d2a8d93.html)，卖车方宣称免费；历史买家侧服务费 4%–9% 已少提及，[红网 2019](https://moment.rednet.cn/content/2019/03/01/5183847.html)）。
- 海外：KBB 三档价中 **Trade-In ≈ Private Party × 75%–85%**（个人出售高 15%–25%，但需承担时间、广告、过户跑腿成本；行业博客口径，仅供参考）。
- 4S 置换：收车价通常压至个人价 9 成上下，但省事 + **置换补贴归购车侧抵扣**（见 1.5）。
- 结论：渠道对比以「个人直卖为基准 100%、置换 ≈ 92%–100% + 补贴、车商收车 ≈ 88%–92%」做**建议区间**，不做成硬输入。

### 1.4 卖车费用与流程

| 项目 | 数值/规则 | 依据 |
| --- | --- | --- |
| 过户费 | 个人过户合计约 **300–800 元**（交易发票费 + 车管所工本约 120 + 可选代办；各地按评估价 0.5%–2% 或固定） | [百度有驾明细](https://kuku.baidu.com/landing/tscp_doc/5e29fa409951dcab08e20c0d42a63fb5)、[知乎实测](https://zhuanlan.zhihu.com/p/2053051795883276067) |
| 增值税 | 个人销售自己使用过的车辆**免征**；经纪/公司撮合或涉 2% | 同上 |
| 商业险退保 | 按天折算：保费 ÷ 保障天数 × 剩余天数 **− 3%–5% 手续费**；须在**过户前**办理 | [新浪 2026 退保新规](https://auto.sina.cn/2026-10-03/detail-initwkuv5364108.d.html)、[太平洋示例](https://m.cpic.com.cn/c/2021-05-31/1644980.shtml) |
| 交强险退保 | 原则上不退；过户/报废等六种情形可在过户前按天退 | [人民网](http://finance.people.com.cn/insurance/n/2012/1207/c59941-19820512.html) |

| 论坛经验 | 卖前清违章、注销 ETC、整备洗美（200–1000 元）可提价；事故/改装显著压价 | 知乎/汽车之家经验帖共识 |

### 1.5 政策联动（2026 以旧换新）

- 政策延续（[商务部 2026 问答手册](https://www.mofcom.gov.cn)，购车页已挂[细则链接](https://www.mofcom.gov.cn/zwgk/zcfb/art/2025/art_2a65998b79af47eaaf2115ef1ce234f9.html)）：报废更新最高 **2 万**；置换更新新能源最高 **2 万** / 燃油最高 **1.5 万**（各地不同，上海按新车价 6% 封顶 1.3 万）。
- 申领条件：旧车 **2025-01-08 前登记在本人名下**、新旧车同一人、旧车过户/报废与新车购置在窗口内、申请截止 2027-01-10（[北京手册](https://www.beijing.gov.cn)）。
- **口径决策**：置换/报废补贴已在购车页抵扣落地总价，卖车模块**不再计收入**（防双算），仅在卖出渠道选择「置换」时提示「别忘了在购车测算页填写置换补贴」。

### 1.6 最佳卖出时点

知乎/央广网/汽车之家共识（[知乎：开几年卖掉最划算](https://www.zhihu.com/question/336591958)、[央广网](http://m.cnr.cn/auto/20160202/t20160202_521308733.html)、[汽车之家](https://chejiahao.autohome.com.cn/info/21035978)）：**前 3 年折旧最陡，4–6 年折旧放缓且维修尚未大涨，年均持有成本最低，是最佳卖出窗口；5 年后维修成本上升**。这正是「年均净支出 U 型曲线」——支撑本模块最有差异化的输出：**逐年净支出对比 + 最优卖出年高亮**。

## 二、口径设计（算什么、不算什么）

**核心规则（防双算）**：全周期净支出 = **落地总价（按卖出时点截断贷款）+ 用车成本（第 1~Y 年）− 卖车到手价**。

| 项目 | 归属 | 规则 |
| --- | --- | --- |
| 落地总价 | 购车侧 | 卖出月早于贷款还清时：月供只计到卖出月（利息止于卖出月），结清余额从卖车款中扣，不进支出侧 |
| 结清余额 | 卖车款内扣 | 到手价 = 卖价 − 结清余额；若购车页「提前还款」早于卖出月，视为已结清（余额 0，落地价沿用其口径，含手续费） |
| 用车成本 | 用车侧 | 复用 `computeOwn` 纯函数按卖出年截断重算（`holdYears = Y`），自动继承 NCD/里程/保养口径；首年险税已在落地价 |
| 残值 | 卖车侧 | 模式一：保值率曲线 × 计税基数（与用车面板折旧参考同基数同曲线）；模式二：手动输入平台估价卖价 |
| 卖车费用 | 卖车侧 | 整备、过户费（默认 400）、平台服务费（默认 0）、其他，计入到手价扣减 |
| 置换/报废/首购补贴 | 购车侧 | 卖车侧不计入（防双算），置换渠道仅提示 |
| 保险退保回收 | P1 | 整年口径（P0）不计；引入卖出月份后：商业险按天退 − 5% 手续费，交强险随车过户不退 |
| 提前还款手续费 | 沿用购车页 | 卖出结清沿用「提前还款手续费」输入值（默认 0，Tip：满 1 年多数机构免收） |
| 折旧（机会成本） | 不计现金 | 用车面板折旧参考行保持「参考」定位；卖车模块把残值**变现为到手价**，两者口径互相衔接 |

**关键公式**：

```
卖出年 Y（1..10，默认跟随用车面板持有年限），卖出月 M = 12Y
残值(卖价) = max(0, 计税基数 × 曲线[能源类型][Y-1])   // 自动模式
          或 手动卖价（手动模式）
结清余额 = (M < 贷款还清月) ? 剩余本金(M, 免息口径与购车页一致) : 0
到手价   = 卖价 − 结清余额 − (整备 + 过户 + 平台 + 其他)
落地(截断) = 首付 + 月供 × min(M, 还清月) + 购置税 + 车船税 + 首年险 + 杂费 − 补贴
            （购车页提前还款早于卖出月时直接取 buyCalc.total）
全周期净支出 = 落地(截断) + 用车成本(1..Y) − 到手价
年均持有成本 = 净支出 / Y；每公里成本 = 净支出 / (年里程 × Y)
逐年表：Y = 1..10 逐个代入上式 → 最优卖出年 = argmin(年均持有成本)，高亮显示
```

需要给 `buyModel.ts` 增加一个导出函数 `remainingPrincipalAt(f, calc, month)`（从现有提前结清公式提炼，免息期口径一致），供截断与结清额计算复用。

## 四、分期落地计划

### P0 · 核心可用（1 个迭代，预计 ~900 行增量）

1. `buyModel.ts`：提炼导出 `remainingPrincipalAt()`（免息口径与现有提前结清一致，~40 行）。
2. `sellModel.ts`：`SellForm` + `computeSell()` 纯函数 + 逐年 1–10 年净支出表 + `buildSellDetailText` + `SELL_SOURCES` + `loadSellForm`（含字段迁移式解析，对齐 own-form 风格）。
3. `SellPanel.tsx`：卖出计划 / 贷款结清展示 / 卖车费用三组输入 + 结果卡 + 逐年表 + 导出三件套。
4. `CarPayCalculator.tsx`：挂载 SellPanel、移除占位与「开发中」徽标、底部条与计算依据区接入 sell。
5. 验收：默认参数（15 万裸车、全款、油车、3 年卖出）→ 到手价 ≈ 计税基数 13.5 万 × 58% ≈ 7.8 万，全周期净支出 ≈ 13.8 万、年均 ≈ 4.6 万（含折旧大头）；贷款 + 3 年卖出时利息须小于全期利息。实测注记：在「其他维修预留」为固定值的口径下，折旧摊薄始终快于维修抬升，年均持有成本到第 10 年仍在缓降，最优卖出年偏向后段——文案不承诺「4-6 年 U 型」，只呈现年均最低点（行业 4-6 年共识源于维修激增与新车迭代，属模型外因素，已在脚注披露）。

### P1 · 精度与联动（第 2 迭代）

1. 卖出月份粒度：能源/杂项按月折算、**商业险退保回收**（按天退 − 5% 手续费，可改）、交强险随车过户提示。
2. 渠道对比建议卡：个人直卖 / 4S 置换 / 车商收车三档到手价区间（个人价 100% / 92%–100% / 88%–92%），置换渠道提示检查购车页补贴字段。
3. 手动卖价与残值率联动微调（自动模式下可改残值率，恢复自动按钮，同购车页购置税交互）。

### P2 · 生态扩展（第 3 迭代）

1. 残值里程修正：年里程显著偏离 2 万 km 基准时按 54321 法扣减。
2. 全周期油电对比扩展：三条能源曲线的逐年净支出对比（衔接用车面板油电对比心智）。
3. 卖车流程 Checklist（违章/ETC/解押/过户前退保）静态卡片，纯文案无计算。
4. 海报 sell 版增强：逐年净支出迷你条形图入图。

### 风险与对策

- **残值争议最大**：曲线来源、基数、手动覆盖三层披露（Tip + 逐年表 + 计算依据外链），手动卖价永远可用兜底。
- **口径混淆**：模块顶部与明细首行固定披露「补贴已入购车页、结清从卖款内扣、折旧已变现」三句口径。
- **贷款截断复杂度**：截断逻辑全部收敛在 buyModel 单一导出函数内，单测覆盖「免息内卖出 / 免息后卖出 / 早于购车页提前还款卖出 / 无贷款」四分支。
- **文件膨胀**：延续 buyModel/ownCostModel 拆分范式，sell 全部收敛在 `sellModel.ts` + `SellPanel.tsx`，主文件只做挂载。

## 六、待拍板问题

1. **残值基准**：沿用「曲线 × 计税基数（成交价）」与用车面板一致（推荐），还是改用厂商指导价口径（数值更高但与折旧参考行不一致）？
2. **默认卖出年份**：首载跟随用车面板持有年限（推荐），还是固定 6 年（行业最优窗口）？
