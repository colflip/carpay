# 补贴快捷选项 · 调研与改进方案

> 调研时间：2026-10-30 · 范围：报废/置换/首购/保险四类补贴的现行政策与行情，给出购车页快捷选项的改进方案。
> 现状：购车页「补贴（抵扣总价，不计税）」区目前是 4 个纯金额输入框（置换 / 报废 / 首购 / 保险），无快捷选项。

---

## 一、关键调研结论

### 1. 报废更新 / 置换更新（2026 国家统一比例制，已执行）
2026 年起国家以旧换新由「定额」改为「按车价比例 + 封顶」，全国统一：

| 路径 | 新能源 | 燃油(2.0L及以下) | 封顶 | 拿满所需车价(含税) |
|---|---|---|---|---|
| 报废更新 | 车价×**12%** | 车价×**10%** | 2万 / 1.5万 | ≥16.67万 / ≥15万 |
| 置换更新 | 车价×**8%** | 车价×**6%** | 1.5万 / 1.3万 | ≥18.75万 / ≥21.67万 |

- 比例基数是「新车销售价格（价税合计）」，即含税开票价。
- 报废与置换每人每年**只能享其一、不可叠加**。
- 地方叠加空间被文件压缩：省级基本同比例；区县消费券多在 1500–6000 元，且与以旧换新多为二选一。
- 来源：发改环资〔2025〕1745 号、商办消费函〔2025〕467 号（gov.cn / ndrc.gov.cn）。

### 2. 首购补贴（地方「购新补贴」为主，无全国统一）
- **国家层面没有「全国首购补贴」**，网传「最高1万、按10%/8%/6%」是把以旧换新上限误传。
- 地方主流是**按车价分档定额**：主流 2000–8000 元/辆，少数城市到 1 万；新能源普遍比燃油多 1000 元。
- 少数城市按比例：苏州 3%(新)/2%(燃)、洛阳 3%、西安 2%，均在 2%–3% 区间。
- 厂家「首购权益」无稳定金额区间（多为尾款减、免息、送电卡等），不宜设默认值。

### 3. 保险补贴 / 赠送保险（固定等值金额为主）
- 4S店「送首年保险」等值约 **2000–8000 元**（对应整张保单），真正让利常是数百至数千元现金/券。
- 首年保费水平（车价分档给默认更准）：10万级约 3000–5000、20万级约 4500–6000、30万级约 6000–8000、豪华 8000–12000+；交强险固定 950（6座以下）/1100。
- **保险补贴按「保费百分比」表达不贴近行情**，固定/等值金额更合适。

## 二、方案设计

### 方案 A · 最小：纯金额快捷芯片（低风险，纯前端）
在 4 个输入框各加一行 `ToggleGroup` 芯片，点击直接填入预设金额：
- 报废：¥15000 / ¥20000
- 置换：¥13000 / ¥15000
- 首购：¥2000 / ¥5000 / ¥8000 / ¥10000
- 保险：¥3000 / ¥5000 / ¥8000
不改计算口径，不动能源类型，不实现比例逻辑。

### 方案 B · 进阶（推荐）：比例 + 2026 政策联动
在方案 A 基础上，让报废/置换支持「金额 ↔ 比例(2026政策)」两种模式：

1. **购车页新增「能源类型」切换（新能源 / 燃油）**，置于补贴区标题旁，默认新能源。
   - 原因：2026 补贴比例与能源类型强绑定；当前购车页不记录能源类型（仅卖车页有）。
2. **报废 / 置换**：每行加一组「2026政策」快捷芯片，点击后读取【含税开票价 = 计税基数 × 1.13】与能源类型，自动算出补贴额填入：
   - 报废·新 12%(封顶2万)、报废·燃 10%(封顶1.5万)
   - 置换·新 8%(封顶1.5万)、置换·燃 6%(封顶1.3万)
   - 比例模式额外带「封顶」输入（默认按上表）；切到比例模式时保留手动金额切换能力。
   - 报废与置换二选一：选其一填额时，另一项给出「不可叠加」提示（不强制清零，避免误删）。
3. **首购**：金额芯片（同 A）+ 比例芯片（车价 2% / 3%），并标注「全国首购补贴为误传，以地方政策为准」。
4. **保险**：金额芯片（同 A），提示「保险栏按保单原价填，补贴仅抵扣总价」。

计算口径不变：补贴仍直接进 `subsNonLoan` 抵扣总价、不计税；比例模式只是自动算出填入金额，下游零改动。

### 方案 C · 完整：在 B 基础上补充明细/海报政策标注
明细文案与导出图对「按政策算出」的补贴加注来源，如「报废补贴 −¥18,000（车价×12% 封顶2万 · 2026政策）」，便于用户核对与截图传播。

## 四、最终决策与实现（2026-10-30 落地）

- **方案 C**：B（比例联动）+ 政策来源标注。
- **能源类型**：复用购车页顶部已有的「车辆类型」Segmented（燃油/新能源），未新增控件。
- **报废 / 置换**：芯片只显示一个百分比（如「6%」），金额由后端按政策算出后填入输入框。
  - 计算：min(含税车价 × 比例, 封顶)，含税车价 = 计税基数 × 1.13；新能源报废 12%/封顶2万、置换 8%/封顶1.5万；燃油报废 10%/封顶1.5万、置换 6%/封顶1.3万。
  - 芯片金额随车价与能源类型实时变化（如 8万车显示 ≈¥9,040，20万车显示 ≈¥15,000 封顶）。
  - 政策模式下切换车价或能源类型会自动重算；手动改数字则切回手动模式，不会被覆盖。
- **首购**：单个「3%」芯片（地方购新补贴常见比例，非全国统一）。
- **保险**：¥950 / ¥2000 / ¥4000 固定额芯片。
- **首付分期**：首付比例芯片 20% / 30% / 40% / 50%（默认 30%）。
- **额度贷款**：贷款额度芯片 5万 / 8万 / 10万（默认 8 万）。
- **不可叠加**：仅提示「报废/置换每年仅享其一」，不自动清零。
- **默认值**：四个补贴默认留空（占位 0），由用户自行选择填写，不做预填。
- **来源标注**：汇总卡与导出明细对政策算出的报废/置换显示「2026政策」及比例/封顶口径，按当前能源类型动态生成。
